\section{مقدمه}
پروژه WarIran با هدف ایجاد یک سیستم هوشمند برای پایش مناطق مختلف ایران با استفاده از داده‌های ماهواره‌ای و حرارتی کلید خورد. در این فاز، زیرساخت اصلی پروژه و اولین موتور تشخیص (حرارتی) پیاده‌سازی شده است.

\section{اقدامات انجام شده}
\begin{itemize}
    \item \textbf{زیرساخت برنامه‌نویسی:} راه‌اندازی ساختار ماژولار پروژه با استفاده از زبان پایتون.
    \item \textbf{استانداردسازی (Docker):} استفاده از Docker برای تضمین اجرای یکسان برنامه در تمامی محیط‌ها.
    \item \textbf{امنیت داده‌ها:} پیاده‌سازی سیستم مدیریت کلیدهای API با استفاده از فایل .env.
    \item \textbf{موتور تشخیص حرارتی (فاز ۱):} اتصال به سرویس NASA FIRMS برای شناسایی نقاط حرارتی.
    \item \textbf{یکپارچه‌سازی ماهواره‌ای (فاز ۲):} اتصال به Google Earth Engine برای تحلیل راداری (SAR).
    \item \textbf{سیستم اطلاع‌رسانی هوشمند (فاز ۳):} راه‌اندازی ربات تلگرام و سیستم ارسال هشدار خودکار.
\end{itemize}

\section{جزئیات سیستم اعلان (فاز ۳)}
در این مرحله، ماژول \texttt{Notifier} پیاده‌سازی شد که وظایف زیر را انجام می‌دهد:
\begin{itemize}
    \item \textbf{ارسال هشدار آنی:} به محض تشخیص حادثه، یک پیام به همراه مختصات جغرافیایی و لینک نقشه گوگل ارسال می‌شود.
    \item \textbf{ارسال جزئیات تحلیل:} شامل درصد اطمینان ناسا و میزان نوسان راداری (Structural Change).
    \item \textbf{پشتیبانی از پروکسی:} جهت عبور از محدودیت‌های شبکه و تضمین ارسال پیام.
\end{itemize}

\section{نتیجه‌گیری نهایی}
سیستم WarIran اکنون یک چرخه کامل از مانیتورینگ را انجام می‌دهد: تشخیص حرارتی $\leftarrow$ تایید ماهواره‌ای $\leftarrow$ ارسال هشدار به کاربر.

    \item طراحی رابط کاربری وب جهت مشاهده گزارش‌ها روی نقشه.
    \item بهینه‌سازی الگوریتم‌های هوش مصنوعی برای کاهش هشدارهای کاذب.
\end{enumerate}
